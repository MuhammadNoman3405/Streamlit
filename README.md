# 🍎 Streamlit Fruit & Age App

A practice project built using **Streamlit** and **Python** to explore interactive web app development.

---

## 🚀 Features

- **🍊 Fruit Inventory Dashboard:** Analyzes fruit cost, revenue, and expiry dates
- **🎂 Age Calculator:** Calculates current age and days remaining until next birthday
- **🗳️ Interactive UI:** Includes voting polls, sidebars, and expanders
- **💱 Live Currency Converter:** Convert currency by entering amount in PKR

---

## 🛠️ Tech Stack

- **Language**: Python 🐍
- **Framework**: Streamlit
- **Libraries**: Pandas, Requests

---

## ▶️ How to Run

1. Clone the repository
2. Install requirements:
```bash
   pip install -r requirements.txt
```
3. Run the app:
```bash
   streamlit run main.py
```
